# Minimalistic Arch

My personal Arch Linux rice built around Hyprland.

## Features

- Hyprland
- Waybar
- Fish shell
- Kitty terminal
- Fastfetch
- Neovim with LazyVim
- Custom wallpapers and configuration

## Installation

**Requirements:** Arch Linux, internet connection, `sudo` privileges.

Install chezmoi and apply the configuration:

```bash
sh -c "$(curl -fsLS https://get.chezmoi.io)" -- init --apply https://github.com/kLarss993/minimalistic-arch.git
```

Review the installation scripts before running them.

## Notes

This configuration is designed for Arch Linux. Package availability, hardware compatibility, and required dependencies may vary.

Back up existing configuration files before applying this rice.
